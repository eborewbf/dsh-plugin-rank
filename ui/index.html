这个插件是做什么的？

GitHub 上 DeepSeek Harness 的插件越来越多，逐个逛仓库太费时间。

本插件把全部 DSH 插件聚合到一个页面里，帮你：排名、推荐、管理。

主要功能

  • 星标排名：按 GitHub 星标数对全部插件排序，并逐条写明「为什么排在当前位置」——星标数、相对名次、被 fork 情况、维护活跃度、是否已归档。
  • 智能推荐：不止看星标，还综合维护活跃度、issue 健康度、增长势头，给出 0-100 的推荐分，并列出每一条推荐理由。
  • 一键管理：直接在页面里安装 / 卸载插件，复用 DSH 官方同款 pnpm 机制，写回 dsh.profile.bundles。

有什么用、有什么好处？

  • 省时：不用逐个逛 GitHub，一次看清生态全景，快速知道哪些插件最受认可。
  • 避坑：排名理由会标注「长期未更新」「已被归档」的插件，避免装到过时、废弃的项目。
  • 选得准：星标高不等于适合你；推荐分综合了活跃度和健康度，帮你挑「活着且在进步」的插件。
  • 装得快：看到就装、不要就卸，全部在页面内完成，改完重启 dsh web 生效。

数据说明

  • 插件来源：GitHub 主题 dsh-plugin / deepseek-harness-plugin / deepseek-harness 的仓库。
  • 结果缓存 6 小时，避免触发 GitHub 限流；抓取失败时自动使用缓存。
  • 设置环境变量 GITHUB_TOKEN 可提高 API 限额，获得更全的数据。

安装 / 使用

1. 在 dsh-plugin-rank 目录执行 pnpm install && pnpm build
2. 在 DSH 安装该插件：dsh plugin add dsh-plugin-rank（或页面内一键安装后）
3. 重启 dsh web，浏览器打开 http://127.0.0.1:3080/plugin-rank/
